## Описание проекта

- Магазин по продаже парфюмерии;
- Базовое spring boot приложение;
- База данных PostgreSql, развертывание через Docker;
- Управление изменениями бд - Liquibase;
- Система контроля версий Maven;
- Тесты пишутся через SpringBootTest;
- Система авторизации/аутентификации: через JWT токены или логин-пароль;
- Фронт на базе html, css. Для интерактивности страниц используется javascript.

## Стартовый воркфлоу

- Прочитать файл PROGRESS.md;
- Прочитать файл PLANS.md;
- Прочитать файл feature-list.json;
- Посмотреть последние коммиты: git log --oneline -5;

Если текущая базовая верификация падает то нужно чинить ее. Не выполнять работу при неисправном стартовом состоянии.

## Тест работоспособности приложения

- Поднять приложение: docker compose up -d + mvn spring-boot:run;
- Прогнать тесты: mvn test;
- Верификация: приложение запустилось без ошибок, все тесты прошли, проверка health-check.

## Defenition of Done

- Фича действительно реализована;
- Проверка фичи сквозными тестами;
- Отсутствие ошибок;
- helth-check;
- Доказательство зафиксированно в feature-list.

## Рабочие правила

- Работать над одной фичей за раз;
- Не помечать фичу сделанной если написан только код;


## Окончание сессии

- Обнови PROGRESS.md;

- Опиши все риски и нерешенные вопросы;
